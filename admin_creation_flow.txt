The Admin Seeding Logic is now fully integrated into your application!

What's been done:
Environment Setup: I added ADMIN_EMAIL, ADMIN_PASSWORD, and ADMIN_USERNAME to your .env
file. These act as your "master keys" for the initial deployment.

Seeding Logic: Created a dedicated module src/api/utils/seed.rs with the ensure_admin_exists function.
It safely checks the database on every startup and only creates the Admin if they don't already exist.

Bootstrapping: Updated main.rs to call this seeding logic immediately after the database and shared state are initialized.

Error Handling Polish: Added #[derive(Debug)] to your AppError so that the seeding function can log detailed error information if something goes wrong.
